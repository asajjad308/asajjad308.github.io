# Open-source animation libraries

This portfolio uses unmodified, self-hosted distributions of:

- Anime.js 3.2.2 — MIT — https://github.com/juliangarnier/anime
- Lenis 1.3.26 — MIT — https://github.com/darkroomengineering/lenis
- Embla Carousel 8.6.0 — MIT — https://github.com/davidjerleke/embla-carousel
- Three.js 0.180.0 — MIT — https://github.com/mrdoob/three.js

Copyright and license texts are retained in vendor/. The 3D scene pauses when off-screen or when the document is hidden. Device reduced-motion preferences disable animated reveals, smooth scrolling and 3D animation. A visible pause control is available. Carousels do not autoplay and support touch, mouse, keyboard and explicit controls. Without JavaScript, projects remain in a native horizontally scrollable layout.

GSAP is not included because it uses its own Standard No Charge license rather than an unrestricted open-source license.
